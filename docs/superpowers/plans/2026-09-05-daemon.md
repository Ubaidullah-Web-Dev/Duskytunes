# Daemon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `duskytunesd`, a Tauri-free daemon that hosts `duskytunes-core` behind a newline-delimited JSON unix socket, plus `duskytunes-cli`, while the Tauri app keeps working unchanged.

**Architecture:** `crates/protocol` defines request/response/event framing. `crates/duskytunesd` owns a tokio runtime, a GTK thread that hosts the hidden WebKitGTK views (cipher, PoToken) and the Google login window through `webkit2gtk-rs`, the socket server that fans `EventSink` events out to subscribers, the MPRIS/tray glue, and the idle-exit lifecycle. `crates/duskytunes-cli` is a thin client for scripts and the shell. Phase 3 (QML client) and phase 4 (cutover) follow in their own plans.

**Tech Stack:** Rust 2021, tokio, serde/serde_json, `webkit2gtk` 2.0 (`v2_40`) + `gtk` 0.18 + `glib` 0.18 (the versions already in `Cargo.lock` via wry), `ksni` 0.3.6 (tray, already in the lock), systemd user units.

**Spec:** `docs/superpowers/specs/2026-09-05-native-client-design.md` (sections 4.3, 4.4, 6; phase 2 of section 8)

## Global Constraints

- Every gate stays green after every task: `cargo fmt --all -- --check`, `cargo test --workspace --locked`, `cargo check --workspace --locked`, `scripts/release-check.sh` (exit 0), `cargo tree -p duskytunes-core -i tauri` errors.
- `crates/core`, `crates/protocol`, `crates/duskytunesd`, `crates/duskytunes-cli` must not depend on `tauri`; `cargo tree -p duskytunesd -i tauri` must error.
- The Tauri app is untouched by this plan except where it starts consuming `crates/protocol` types (none required). Its behaviour and gates do not change.
- New dependencies allowed, each pinned to a version already in `Cargo.lock`: `gtk = "0.18"`, `glib = "0.18"`, `webkit2gtk = "2.0"` (features `v2_40`), `ksni = "0.3"`, `clap = "4"` (check the lock first; if `clap` is absent use `std::env::args` and skip it). Nothing else.
- Socket path `$XDG_RUNTIME_DIR/duskytunes/duskytunesd.sock`; directory `0700`; socket created under `umask 077`; lock file `duskytunesd.sock.lock` held with `flock(LOCK_EX | LOCK_NB)` for the process lifetime.
- Wire format: one JSON object per line, UTF-8, `\n` terminated, no framing beyond that. Request `{"id":u64,"method":str,"params":Value}`; response `{"id":u64,"result":Value}` or `{"id":u64,"error":{"code":str,"message":str}}`; event `{"event":str,"data":Value}`.
- Method names and JSON shapes are exactly the 92 `#[tauri::command]` names/parameters/results in `src-tauri/src/commands.rs`; parameter objects use the same camelCase keys the Svelte `ui/src/lib/api.ts` sends (Tauri converts `video_id` to `videoId`; the daemon must accept the camelCase form). Plus `hello`, `subscribe`, `show`, `quit`, `sign_in`.
- Commit subjects: `daemon: ...`, `protocol: ...`, `cli: ...`, imperative, no trailing period, no attribution trailers.

```rust
pub use wire::{ErrorBody, Event, Incoming, Outgoing, Request, Response, PROTOCOL_VERSION};

use std::path::PathBuf;

/// `$XDG_RUNTIME_DIR/duskytunes/duskytunesd.sock`, or `/tmp/duskytunes-<uid>/duskytunesd.sock` without a
/// runtime dir (a bare TTY login). The directory is created by the daemon with mode 0700.
pub fn socket_path() -> PathBuf {
    let dir = std::env::var_os("XDG_RUNTIME_DIR")
        .map(PathBuf::from)
        .unwrap_or_else(|| std::env::temp_dir().join(format!("duskytunes-{}", unsafe { libc_uid() })));
    dir.join("duskytunes").join("duskytunesd.sock")
}

// No libc dependency for one call: read the uid from the kernel.
unsafe fn libc_uid() -> u32 {
    std::fs::read_to_string("/proc/self/loginuid").ok().and_then(|s| s.trim().parse().ok()).unwrap_or(0)
}
```

```rust
pub const PROTOCOL_VERSION: u32 = 1;

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct Request {
    pub id: u64,
    pub method: String,
    #[serde(default)]
    pub params: Value,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct ErrorBody {
    pub code: String,
    pub message: String,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct Response {
    pub id: u64,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub result: Option<Value>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub error: Option<ErrorBody>,
}

impl Response {
    pub fn ok(id: u64, result: Value) -> Self {
        Response { id, result: Some(result), error: None }
    }
    pub fn err(id: u64, code: &str, message: impl Into<String>) -> Self {
        Response { id, result: None, error: Some(ErrorBody { code: code.into(), message: message.into() }) }
    }
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct Event {
    pub event: String,
    pub data: Value,
}

/// What a client may send. Only requests today; the enum leaves room for a `cancel`.
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
#[serde(untagged)]
pub enum Incoming {
    Request(Request),
}

/// What the daemon sends.
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
#[serde(untagged)]
pub enum Outgoing {
    Response(Response),
    Event(Event),
}

impl Outgoing {
    /// One line, newline included.
    pub fn to_line(&self) -> String {
        let mut s = serde_json::to_string(self).expect("wire types serialize");
        s.push('\n');
        s
    }
}
```

```rust
//! `EventSink` over the socket: every event goes to every connection that subscribed.

use std::sync::atomic::{AtomicUsize, Ordering};
use std::sync::{Arc, Mutex};

use duskytunes_core::host::EventSink;
use duskytunes_protocol::{Event, Outgoing};
use serde_json::Value;
use tokio::sync::mpsc::UnboundedSender;

#[derive(Default)]
pub struct SocketSink {
    subscribers: Mutex<Vec<UnboundedSender<String>>>,
    count: AtomicUsize,
}

impl SocketSink {
    pub fn subscribe(&self, tx: UnboundedSender<String>) {
        self.subscribers.lock().unwrap().push(tx);
        self.count.fetch_add(1, Ordering::Relaxed);
    }

    pub fn subscriber_count(&self) -> usize {
        self.count.load(Ordering::Relaxed)
    }

    fn prune(&self, subs: &mut Vec<UnboundedSender<String>>) {
        let before = subs.len();
        subs.retain(|tx| !tx.is_closed());
        let dropped = before - subs.len();
        if dropped > 0 {
            self.count.fetch_sub(dropped, Ordering::Relaxed);
        }
    }
}

impl EventSink for Arc<SocketSink> {
    fn emit(&self, event: &'static str, payload: Value) {
        let line = Outgoing::Event(Event { event: event.to_owned(), data: payload }).to_line();
        let mut subs = self.subscribers.lock().unwrap();
        self.prune(&mut subs);
        for tx in subs.iter() {
            let _ = tx.send(line.clone());
        }
    }
}
```

```rust
//! Unix-socket server: one task per connection, requests dispatched concurrently, responses
//! and events multiplexed through a per-connection writer task.

use std::os::unix::fs::PermissionsExt;
use std::path::Path;
use std::sync::Arc;

use duskytunes_protocol::{ErrorBody, Incoming, Outgoing, Request, Response};
use serde_json::Value;
use tokio::io::{AsyncBufReadExt, AsyncWriteExt, BufReader};
use tokio::net::{UnixListener, UnixStream};
use tokio::sync::mpsc;

use crate::sink::SocketSink;

#[async_trait::async_trait]
pub trait Dispatch: Send + Sync + 'static {
    async fn call(&self, method: &str, params: Value, conn: &Connection) -> Result<Value, ErrorBody>;
}

/// What a method handler may do to the connection it arrived on.
pub struct Connection {
    pub tx: mpsc::UnboundedSender<String>,
    pub sink: Arc<SocketSink>,
}

impl Connection {
    /// `subscribe`: from now on every event reaches this connection.
    pub fn subscribe(&self) {
        self.sink.subscribe(self.tx.clone());
    }
}

pub struct Server {
    listener: UnixListener,
    sink: Arc<SocketSink>,
}

impl Server {
    /// Bind with the directory at 0700 and the socket at 0600 (created under umask 077).
    pub fn bind(path: &Path, sink: Arc<SocketSink>) -> std::io::Result<Server> {
        let dir = path.parent().expect("socket path has a parent");
        std::fs::create_dir_all(dir)?;
        std::fs::set_permissions(dir, std::fs::Permissions::from_mode(0o700))?;
        let _ = std::fs::remove_file(path);
        // Safe: umask is process-global and we restore it immediately; nothing else creates
        // files during this window (the daemon is single-threaded until `run`).
        let old = unsafe { libc::umask(0o077) };
        let listener = UnixListener::bind(path);
        unsafe { libc::umask(old) };
        Ok(Server { listener: listener?, sink })
    }

    pub async fn run(self, dispatch: Arc<dyn Dispatch>) {
        loop {
            match self.listener.accept().await {
                Ok((stream, _)) => {
                    tokio::spawn(handle(stream, dispatch.clone(), self.sink.clone()));
                }
                Err(e) => tracing::warn!(error = %e, "accept failed"),
            }
        }
    }
}

async fn handle(stream: UnixStream, dispatch: Arc<dyn Dispatch>, sink: Arc<SocketSink>) {
    let (rd, mut wr) = stream.into_split();
    let (tx, mut rx) = mpsc::unbounded_channel::<String>();
    let writer = tokio::spawn(async move {
        while let Some(line) = rx.recv().await {
            if wr.write_all(line.as_bytes()).await.is_err() {
                break;
            }
        }
    });
    let conn = Arc::new(Connection { tx: tx.clone(), sink });
    let mut lines = BufReader::new(rd).lines();
    while let Ok(Some(line)) = lines.next_line().await {
        let req = match serde_json::from_str::<Incoming>(&line) {
            Ok(Incoming::Request(r)) => r,
            Err(e) => {
                let _ = tx.send(Outgoing::Response(Response::err(0, "bad_request", e.to_string())).to_line());
                continue;
            }
        };
        let dispatch = dispatch.clone();
        let conn = conn.clone();
        let tx = tx.clone();
        tokio::spawn(async move {
            let Request { id, method, params } = req;
            let resp = match dispatch.call(&method, params, &conn).await {
                Ok(v) => Response::ok(id, v),
                Err(e) => Response { id, result: None, error: Some(e) },
            };
            let _ = tx.send(Outgoing::Response(resp).to_line());
        });
    }
    drop(tx);
    let _ = writer.await;
}
```

```rust
//! One thread owns GTK. Everything WebKit is marshalled onto it; nothing else touches GTK.

use std::future::Future;

use tokio::sync::oneshot;

#[derive(Clone)]
pub struct Gtk {
    ctx: glib::MainContext,
}

impl Gtk {
    /// Start the GTK main loop on its own thread and return a handle. Panics if GTK cannot
    /// initialise (no display): the daemon then refuses to start, which is the right answer
    /// because the cipher/PoToken path needs a display.
    pub fn start() -> Gtk {
        let (tx, rx) = std::sync::mpsc::channel();
        std::thread::Builder::new()
            .name("gtk".into())
            .spawn(move || {
                gtk::init().expect("GTK init (is WAYLAND_DISPLAY/DISPLAY set?)");
                let ctx = glib::MainContext::default();
                tx.send(ctx.clone()).unwrap();
                gtk::main();
            })
            .expect("spawn gtk thread");
        Gtk { ctx: rx.recv().expect("gtk thread reported its context") }
    }

    /// Run `f` on the GTK thread and await its result.
    pub fn call<R: Send + 'static>(&self, f: impl FnOnce() -> R + Send + 'static) -> impl Future<Output = R> {
        let (tx, rx) = oneshot::channel();
        self.ctx.invoke(move || {
            let _ = tx.send(f());
        });
        async move { rx.await.expect("gtk closure ran") }
    }
}
```

```rust
use std::collections::HashMap;
use std::sync::{Arc, Mutex};
use std::time::{Duration, Instant};

use duskytunes_core::host::{JsBridge, JsError, JsSession};
use serde_json::Value;
use webkit2gtk::{gio, glib, WebView, WebViewExt};

use crate::gtk_thread::Gtk;

pub struct GtkJs {
    gtk: Gtk,
    views: Arc<Mutex<HashMap<String, WebView>>>,
}

impl GtkJs {
    pub fn new(gtk: Gtk) -> Self {
        GtkJs { gtk, views: Arc::new(Mutex::new(HashMap::new())) }
    }
}

#[derive(Clone)]
pub struct Session {
    gtk: Gtk,
    label: String,
    views: Arc<Mutex<HashMap<String, WebView>>>,
}

impl Session {
    fn view(&self) -> Result<WebView, JsError> {
        self.views.lock().unwrap().get(&self.label).cloned().ok_or_else(|| JsError::Gone(self.label.clone()))
    }
}

#[async_trait::async_trait]
impl JsBridge for GtkJs {
    async fn create(&self, label: &str, harness_html: &str, init_script: &str) -> Result<Box<dyn JsSession>, JsError> {
        self.reclaim(label).await;
        let init = format!(
            "window.__jserr=null;window.__slots={{}};\
             window.addEventListener('error',function(e){{window.__jserr=String((e&&e.message)||e);}});\
             window.onunhandledrejection=function(e){{window.__jserr=String((e.reason&&e.reason.message)||e.reason);}};\n{init_script}"
        );
        let data_url = format!("data:text/html,{}", urlencoding::encode(harness_html));
        let label_s = label.to_owned();
        let views = self.views.clone();
        self.gtk
            .call(move || {
                use webkit2gtk::{UserContentInjectedFrames, UserContentManagerExt, UserScript, UserScriptInjectionTime};
                let ucm = webkit2gtk::UserContentManager::new();
                ucm.add_script(&UserScript::new(&init, UserContentInjectedFrames::TopFrame, UserScriptInjectionTime::Start, &[], &[]));
                let view = WebView::builder().user_content_manager(&ucm).build();
                let win = gtk::OffscreenWindow::new();
                use gtk::prelude::*;
                win.add(&view);
                win.show_all();
                view.load_uri(&data_url);
                views.lock().unwrap().insert(label_s, view);
            })
            .await;
        let session = Session { gtk: self.gtk.clone(), label: label.to_owned(), views: self.views.clone() };
        let deadline = Instant::now() + Duration::from_secs(12);
        loop {
            if matches!(session.eval_json("location.protocol==='data:'".into(), Duration::from_millis(800)).await, Ok(Value::Bool(true))) {
                tracing::info!(label, "js bridge OK");
                return Ok(Box::new(session));
            }
            if Instant::now() >= deadline {
                session.destroy();
                return Err(JsError::Timeout(Duration::from_secs(12)));
            }
            tokio::time::sleep(Duration::from_millis(150)).await;
        }
    }

    async fn reclaim(&self, label: &str) {
        let label = label.to_owned();
        let views = self.views.clone();
        self.gtk
            .call(move || {
                if let Some(v) = views.lock().unwrap().remove(&label) {
                    use gtk::prelude::*;
                    if let Some(w) = v.toplevel() {
                        unsafe { w.destroy() };
                    }
                }
            })
            .await;
    }
}

#[async_trait::async_trait]
impl JsSession for Session {
    fn eval(&self, js: &str) -> Result<(), JsError> {
        let view = self.view()?;
        let js = js.to_owned();
        // Fire and forget on the GTK thread; the result is discarded like Tauri's `eval`.
        let _ = self.gtk.call(move || view.evaluate_javascript(&js, None, None, None::<&gio::Cancellable>, |_| {}));
        Ok(())
    }

    async fn eval_json(&self, js: String, timeout: Duration) -> Result<Value, JsError> {
        let view = self.view()?;
        let (tx, rx) = tokio::sync::oneshot::channel::<Result<String, String>>();
        let tx = Arc::new(Mutex::new(Some(tx)));
        self.gtk
            .call(move || {
                view.evaluate_javascript(&js, None, None, None::<&gio::Cancellable>, move |res| {
                    let out = match res {
                        Ok(v) => Ok(v.to_json(0).map(|g| g.to_string()).unwrap_or_else(|| "null".into())),
                        Err(e) => Err(e.to_string()),
                    };
                    if let Some(tx) = tx.lock().unwrap().take() {
                        let _ = tx.send(out);
                    }
                })
            })
            .await;
        let raw = tokio::time::timeout(timeout, rx)
            .await
            .map_err(|_| JsError::Timeout(timeout))?
            .map_err(|_| JsError::Eval("callback dropped".into()))?
            .map_err(JsError::Eval)?;
        if raw.is_empty() || raw == "null" || raw == "undefined" {
            return Ok(Value::Null);
        }
        serde_json::from_str(&raw).map_err(|e| JsError::Eval(format!("bad json {raw:?}: {e}")))
    }

    async fn call_async(&self, expr: &str, timeout: Duration) -> Result<Value, JsError> {
        // Verbatim port of `webview.rs` `call_async` + `poll_json` on top of `eval`/`eval_json`.
        static NEXT: std::sync::atomic::AtomicU64 = std::sync::atomic::AtomicU64::new(1);
        let id = NEXT.fetch_add(1, std::sync::atomic::Ordering::Relaxed);
        self.eval(&format!(
            "(async()=>{{try{{window.__slots['{id}']={{ok:1,v:await ({expr})}};}}\
             catch(e){{window.__slots['{id}']={{ok:0,e:String((e&&e.message)||e)}};}}}})();"
        ))?;
        let deadline = Instant::now() + timeout;
        let slot = loop {
            match self.eval_json(format!("(window.__slots['{id}']||null)"), Duration::from_secs(3)).await {
                Ok(v) if !v.is_null() => break v,
                Ok(_) => {}
                Err(JsError::Gone(l)) => return Err(JsError::Gone(l)),
                Err(_) => {}
            }
            if let Ok(Value::String(msg)) = self.eval_json("window.__jserr||null".into(), Duration::from_secs(3)).await {
                return Err(JsError::BadEnvironment(msg));
            }
            if Instant::now() >= deadline {
                return Err(JsError::Timeout(timeout));
            }
            tokio::time::sleep(Duration::from_millis(100)).await;
        };
        let _ = self.eval(&format!("delete window.__slots['{id}'];"));
        if slot.get("ok").and_then(Value::as_i64) == Some(1) {
            Ok(slot.get("v").cloned().unwrap_or(Value::Null))
        } else {
            Err(JsError::Eval(slot.get("e").and_then(Value::as_str).unwrap_or("async call failed").to_owned()))
        }
    }

    fn exists(&self) -> bool {
        self.views.lock().unwrap().contains_key(&self.label)
    }

    fn destroy(&self) {
        let label = self.label.clone();
        let views = self.views.clone();
        let _ = self.gtk.call(move || {
            if let Some(v) = views.lock().unwrap().remove(&label) {
                use gtk::prelude::*;
                if let Some(w) = v.toplevel() {
                    unsafe { w.destroy() };
                }
            }
        });
    }

    fn clone_session(&self) -> Box<dyn JsSession> {
        Box::new(self.clone())
    }
}
```

```rust
//! Every socket method. Names, parameter keys and result shapes are the Tauri commands'.

use std::sync::Arc;

use duskytunes_core::state::AppState;
use duskytunes_protocol::{ErrorBody, PROTOCOL_VERSION};
use serde::de::DeserializeOwned;
use serde_json::{json, Value};

use crate::server::{Connection, Dispatch};

pub struct Methods {
    pub state: Arc<AppState>,
    pub quit: tokio::sync::mpsc::UnboundedSender<()>,
}

fn arg<T: DeserializeOwned>(params: &Value, key: &str) -> Result<T, ErrorBody> {
    serde_json::from_value(params.get(key).cloned().unwrap_or(Value::Null))
        .map_err(|e| ErrorBody { code: "bad_params".into(), message: format!("{key}: {e}") })
}

fn err(e: impl ToString) -> ErrorBody {
    ErrorBody { code: "failed".into(), message: e.to_string() }
}

fn ok<T: serde::Serialize>(v: T) -> Result<Value, ErrorBody> {
    serde_json::to_value(v).map_err(err)
}

#[async_trait::async_trait]
impl Dispatch for Methods {
    async fn call(&self, method: &str, params: Value, conn: &Connection) -> Result<Value, ErrorBody> {
        let st = &self.state;
        match method {
            "hello" => ok(json!({ "protocol": PROTOCOL_VERSION, "daemon": env!("CARGO_PKG_VERSION") })),
            "subscribe" => {
                conn.subscribe();
                ok(json!({
                    "playback": st.playback_snapshot().await,
                    "queue": st.queue_snapshot().await,
                    "settings": st.settings_snapshot(),
                    "auth": st.account_snapshot().await,
                }))
            }
            "quit" => {
                let _ = self.quit.send(());
                ok(Value::Null)
            }
            "search" => ok(st.search(&arg::<String>(&params, "query")?).await.map_err(err)?),
            "search_page" => ok(st.search_page(&arg::<String>(&params, "query")?).await.map_err(err)?),
            // ... one arm per command in src-tauri/src/commands.rs, in the same order, each
            // decoding the command's parameters with `arg` under the camelCase key the Svelte
            // api.ts sends and calling the same AppState method the command forwards to ...
            "play" => {
                st.play(arg(&params, "item")?).await.map_err(err)?;
                ok(Value::Null)
            }
            "seek" => {
                st.seek(arg::<f64>(&params, "position")?).await.map_err(err)?;
                ok(Value::Null)
            }
            "sign_in" => {
                st.sign_in().await;
                ok(Value::Null)
            }
            "frontend_ready" | "open_mini" | "close_mini" | "login_webview" => {
                Err(ErrorBody { code: "client_side".into(), message: format!("{method} is handled by the client") })
            }
            _ => Err(ErrorBody { code: "unknown_method".into(), message: method.into() }),
        }
    }
}
```

```rust
        app::spawn_pumps(state.clone(), events, media_rx, lt_rx, sink.clone());
        let (quit_tx, mut quit_rx) = tokio::sync::mpsc::unbounded_channel();
        let server = server::Server::bind(&path, sink.clone())?;

            _ = server.run(methods) => {}
            _ = quit_rx.recv() => {}
            _ = tokio::signal::ctrl_c() => {}

        state.shutdown().await; // stop mpv, unregister MPRIS, flush position (what `request_quit` does today)

    })?;
    drop(lock);
    let _ = std::fs::remove_file(&path);
    Ok(())
}
```

```rust
//! `duskytunes-cli <method> [json-params]` or `duskytunes-cli events [names...]`.

use std::io::{BufRead, BufReader, Write};
use std::os::unix::net::UnixStream;

use duskytunes_protocol::{Outgoing, Request};

fn parse(args: &[String]) -> Result<(Option<std::path::PathBuf>, Request, bool), String> {
    let mut socket = None;
    let mut rest = args.to_vec();
    if rest.first().map(String::as_str) == Some("--socket") {
        rest.remove(0);
        socket = Some(rest.first().ok_or("--socket needs a path")?.into());
        rest.remove(0);
    }
    let method = rest.first().ok_or("usage: duskytunes-cli [--socket PATH] <method> [json] | events [name...]")?.clone();
    if method == "events" {
        let names: Vec<String> = rest[1..].to_vec();
        let params = if names.is_empty() { serde_json::json!({ "events": ["*"] }) } else { serde_json::json!({ "events": names }) };
        return Ok((socket, Request { id: 1, method: "subscribe".into(), params }, true));
    }
    let params = match rest.get(1) {
        Some(raw) => serde_json::from_str(raw).map_err(|e| format!("params: {e}"))?,
        None => serde_json::Value::Null,
    };
    Ok((socket, Request { id: 1, method, params }, false))
}

fn main() {
    let args: Vec<String> = std::env::args().skip(1).collect();
    let (socket, req, follow) = match parse(&args) {
        Ok(v) => v,
        Err(e) => {
            eprintln!("{e}");
            std::process::exit(2);
        }
    };
    let path = socket.unwrap_or_else(duskytunes_protocol::socket_path);
    let mut stream = match UnixStream::connect(&path) {
        Ok(s) => s,
        Err(e) => {
            eprintln!("duskytunesd not reachable at {}: {e}", path.display());
            std::process::exit(3);
        }
    };
    let mut line = serde_json::to_string(&req).unwrap();
    line.push('\n');
    stream.write_all(line.as_bytes()).unwrap();
    let reader = BufReader::new(stream.try_clone().unwrap());
    for l in reader.lines() {
        let l = match l { Ok(l) => l, Err(_) => break };
        match serde_json::from_str::<Outgoing>(&l) {
            Ok(Outgoing::Response(r)) => {
                if let Some(e) = r.error {
                    println!("{}", serde_json::to_string(&e).unwrap());
                    std::process::exit(1);
                }
                if !follow {
                    println!("{}", r.result.unwrap_or(serde_json::Value::Null));
                    return;
                }
            }
            Ok(Outgoing::Event(ev)) => {
                if follow {
                    println!("{}", serde_json::to_string(&ev).unwrap());
                }
            }
            Err(_) => eprintln!("unparsable line: {l}"),
        }
    }
}
```
